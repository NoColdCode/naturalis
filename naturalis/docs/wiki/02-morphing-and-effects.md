## Morph Binding

`Morph Binding` is a control effect that locks your morph state for a duration.

What you should expect:

- Morph swapping is restricted while binding is active
- Certain actions are intentionally blocked to enforce the lock
- Lightning flavor events can occur while bound and morphed

Tip: if you get bound often, increase your knowledge with that morph to reduce surge risk during Resonance.

## Brewed Morph

`Brewed Morph` applies a temporary morph target from potion data.

What you should expect:

- Potion only works if a valid morph target is set
- Duration is fixed by the potion or command settings
- Useful for temporary adaptation or roleplay scenarios

## Instinct and body-feel systems

Naturalis includes systems that make different bodies feel different:

- Diet compatibility and penalties
- Movement/body traits (quadruped, flight-only, aquatic, and more)
- Environment susceptibility by morph type

The goal is not only visual change, but behavior change.
