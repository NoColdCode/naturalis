# Instinct

Instinct is automatic behavior pressure tied to morph identity.

As your instinct and wander ranks improve, instinct interruptions become rarer and can be fully disabled.

## Instinct check timing by rank

- Rank 0: every `1 tick`
- Rank 1: every `2 ticks`
- Rank 2: every `4 ticks`
- Rank 3: every `8 ticks`
- Rank 4: every `14 ticks`
- Rank 5: disabled

## AFK wander timing by rank

- Rank 0: after `300 ticks` (`15 s`) AFK
- Rank 1: `450 ticks` (`22.5 s`)
- Rank 2: `700 ticks` (`35 s`)
- Rank 3: `1000 ticks` (`50 s`)
- Rank 4: `1400 ticks` (`70 s`)
- Rank 5: disabled

## Wander movement envelope

- Wander target distance range: `5` to `10` blocks
- Instinct horizontal speed cap: `0.28`
- Prey push speed cap: `0.26`

## Hunt windows

When hunt instinct triggers:
- Active hunt window lasts `120 ticks` (`6 s`)

## Feral override (Lost humanity)

In Lost stage while aligned and Resonance active:
- Instinct checks run at full pressure (`every tick`)
- Extra feral combat buffs can apply (night vision, speed, strength, resistance)

## Manual override behavior

Strong manual movement input can suppress active steering loops, so you can wrest back control during instinct events.
