# Quick Start

This page helps you start playing Naturalis quickly.

## 1. Basic loop

1. Acquire morphs (for example with the Echo Gem or server commands).
2. Use your morph and survive in that form.
3. Gain knowledge levels for that morph.
4. Unlock advanced gameplay once a morph is mastered.

## 2. Open the knowledge screen

Use your keybind for Morph Knowledge (`Open Morph Knowledge`).

The screen shows:

- Current knowledge level
- XP progress
- Diet and trait info
- Feature hints

## 3. Learn how knowledge grows

Knowledge improves by behaving like the creature:

- Staying morphed over time
- Moving with that body
- Using movement traits (swim, fly, climb, and so on)
- Surviving combat and world hazards

## 4. Important early items

- `Echo Collector`: captures echo progress from valid targets
- `Echo Gem`: helps acquire morphs
- `Brewed Morph Potion`: temporary morph effect with a specific target

## 5. Move to advanced gameplay

When you fully master one morph, continue with `03-resonance-guide.md`.
