# Welcome to Naturalis Wiki

Naturalis is a survival morph progression mod where each body has real advantages, limits, and long-term mastery.

Current stable version: **1.6.0**

## Start here

1. Read [Patch Notes 1.6.0](patch-notes-1.6.0.md)
2. Read [Patch Notes 1.4.0](patch-notes-1.4.0.md) (Resonance & Humanity baseline)
3. Continue to [Basics Index](../10-basics/README.md)
4. Then read [Mechanisms Index](../20-mechanisms/README.md)
5. Finish with [Lore and Risks Index](../30-lore-and-risks/README.md)

## Core identity in one line

You do not just wear morph skins in Naturalis. You learn bodies, manage instincts, and decide how far you go before losing your humanity.
